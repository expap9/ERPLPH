# หน้าจอ ERPLPH — ดูข้อมูลแบบ Stock5 ครบทุกประเภทของ

> ผู้ใช้สั่ง 17 ก.ย. 2569: *"อยากได้การดูข้อมูลเหมือน stock5 ครับ แต่ว่าตัดส่วนของข้อมูลส่งกระทรวงออก
> และดูได้ทุกอย่าง ทุกประเภทของ ยา อาหาร พัสดุ งานจ้าง งานก่อสร้าง วัสดุคอมพิวเตอร์ทุกอย่าง"*

เปิดด้วย `run_web.bat` แล้วเข้า `http://127.0.0.1:8090`

## 1. หน้าเทียบกับ Stock5

| ERPLPH | เทียบกับ Stock5 | ขอบเขต |
|---|---|---|
| `/` ภาพรวม | Dashboard ภาพรวมคลังยา | ทุกกลุ่มของ ทุกคลัง กรองได้ 3–24 เดือน |
| `/items` ค้นหารายการ | ค้นหาและตรวจสอบข้อมูล | ค้นรหัส/ชื่อ ข้ามทุกกลุ่ม |
| `/items/<รหัส>` | รายละเอียดเวชภัณฑ์ | คงคลังรายคลังรายล็อต · รับ/ใช้รายเดือน · ผู้ขาย · ใบรับ · หน่วยงานที่เบิก |
| `/lists/expiring` `/lists/dormant` | การ์ดใกล้หมดอายุ / ไม่พบประวัติเบิกจ่าย | กดจากการ์ดหน้าภาพรวม |
| `/departments` | มูลค่าการเบิกจ่ายแยกตามหน่วยเบิก | ลงได้ 3 ชั้นถึงรายการ |
| `/cut-status` | — (ไม่มีใน Stock5) | คลังไหนหยุดตัดยอด |

**ไม่ได้ทำ (ตั้งใจ):** ส่งข้อมูลกระทรวง · กำหนดชื่อตาราง · ตั้งค่า
**ยังไม่ได้ทำ:** ใบ PO ค้างรับ/รับแล้ว · แผนจัดซื้อเทียบงบประมาณ · ส่วนของด้านจัดซื้อ 8 ตาราง

## 2. กติกาตัวเลขที่ใช้ร่วมกันทุกหน้า

| ตัวเลข | นิยาม | ที่มาของกติกา |
|---|---|---|
| ยอดใช้ทั้งโรงพยาบาล | ใบจ่ายให้หน่วยเบิก (ชนิด 32) ขาออกที่สอบทานผ่าน หักใบคืนทั้งหมด ไม่นับการโอน | ผู้ใช้ตัดสิน 11 ก.ย. 2569 |
| ยอดใช้รายคลัง | นับการโอนออกด้วย | `metrics.py` — คลังหลักจ่ายออกด้วยการโอน |
| ช่วง N เดือน | เดือนที่จบแล้วเท่านั้น นับถอยจากงวดล่าสุดที่มีข้อมูล | `metrics.py` |
| ยอดรับ | ใบรับจากการซื้อ จ้าง รับบริจาค | `queries._MAIN_STORE_RECEIPT_NUMBERING` |
| เดือนคงคลัง | มูลค่าคงคลัง ÷ ยอดใช้เฉลี่ย · ไม่คิดกับครุภัณฑ์และงานจ้าง | `categories.CONSUMABLE_GROUPS` |
| กลุ่มของ | คำนวณจากหมวดของรายการตอนอ่าน แบ่งกลุ่มใหม่ไม่ต้องดึงข้อมูลใหม่ | `categories.GROUPS` |

ยืนยันแล้วว่ายอดใช้หน้าภาพรวมตรงกับหน้ารายแผนกทุกบาท (1,585,358,201 บาท 12 เดือน ก.ย. 68 – ส.ค. 69)
มีเทสต์ตรึงไว้ `tests/test_overview.py`

## 4. ต้องรู้ก่อนนำเสนอ

- **ยอดรับยังไม่ครบ** จนกว่าจะรัน `pull_warehouse_data.bat` หลัง commit `75d46c1` — ก่อนหน้านั้นตัวดึง
  เก็บใบรับได้แค่คลังยา หน้าภาพรวมขึ้นกล่องเตือนเองเมื่อใบรับมีคลังเดียว
- หน่วยงานที่ **เบิก** ไม่ใช่หน่วยงานที่ **ใช้** เสมอไป — ห้องยาเบิกแทนหอผู้ป่วย
- คงคลังของคลังที่หยุดตัดยอด (ดู `/cut-status`) สูงกว่าจริง เช่น ห้องยาผู้ป่วยนอกตึก 8 ชั้น
