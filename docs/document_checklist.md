# เอกสารที่ต้องการ ก่อนสร้างตัวชี้วัดกลุ่ม ข และ ค

ตามกติกา "ไม่เดา" (ตกลง 11 กันยายน 2569): ตัวเลขที่ขึ้นแดชบอร์ดต้องมาจากช่องที่
ระบบบันทึกเอง หรือยืนยันจากเอกสารจริง เอกสารชุดนี้ใช้ยืนยันว่าแต่ละขั้นของงานจริง
บันทึกไว้ที่ไหนในระบบ SSB

## วิธีถ่าย

- ถ่าย **เคสจริงให้ครบวงจรของเคสเดียวกัน** เลขเอกสารต้องอ้างถึงกันได้
- ถ่าย **หน้าจอ SSB ตอนบันทึกเอกสารนั้น** คู่กัน ชื่อเมนูและชื่อช่องบอกได้ว่าข้อมูลอยู่ตารางไหน
- ในภาพต้องเห็น **เลขที่เอกสาร วันที่ จำนวนเงิน และเลขเอกสารที่อ้างถึง**
- **ปิดก่อนถ่าย:** เลขบัญชีธนาคาร ลายเซ็น เลขบัตรประชาชน ชื่อผู้ป่วย และ HN
- ขาดเอกสารไหน ให้จดว่า "ไม่มี" ข้อมูลนี้บอกจุดที่งานค้างได้เหมือนกัน
- ชื่อเอกสารในรายการนี้อาจไม่ตรงกับที่โรงพยาบาลเรียก ถ่ายตามที่มีใช้จริง

## 0. หน้าจอระบบ ไม่ต้องใช้เอกสาร (ทำก่อน ใช้เวลาน้อย ตอบได้หลายข้อ)

- [ ] เมนูหลักของ SSB ทุกระบบที่โรงพยาบาลเปิดใช้ (คลัง จัดซื้อ การเงิน บัญชี ครุภัณฑ์ ฯลฯ)
- [ ] หน้าจอกำหนดหมวด/ประเภทพัสดุ (รหัสหมวดคู่กับชื่อ) — ยืนยันการแบ่ง 4 กลุ่ม
- [x] หน้าจอกำหนดวิธีซื้อ/ประเภทการซื้อ — **พบแล้ว 15 ก.ย. 2569** (จากงาน Stock5): หน้าจอ
      "Purchase Type" ของ SSB ใช้ช่อง **Code** (ห้ามอ่าน Name Eng.) เทียบรหัสกระทรวง I_buy_method
      ได้ครบ: 11→10, 2→13, 22→20, 33→30, 331→32, 332→33, 333→38, 9→12, 95/96/97 คงเดิม และใบรับ
      บริจาค (MRS) ไม่มีรหัส ใช้ 99 — ดู `app/mappings.json` ของ Stock5
- [ ] หน้าจอกำหนดเลขที่เอกสาร (คำนำหน้าเลขแต่ละประเภท) ถ้ามี

- [ ] ใบสั่งซื้อฉบับร่าง (หน้าจอ Transfer Pre P/O) และใบสั่งซื้อที่ลงนามแล้ว
- [ ] ใบส่งของ / ใบแจ้งหนี้ / ใบกำกับภาษีของบริษัท
- [ ] ใบตรวจรับพัสดุ (คณะกรรมการตรวจรับ)
- [x] ใบรับเข้าคลัง — **พบแล้ว 14 ก.ย. 2569**: "ใบนำส่งเวชภัณฑ์เข้าคลัง" พิมพ์จาก SSB ผูก
      เลขที่ใบรับ (M...) ↔ เลขที่ใบส่งของ ↔ ผู้จำหน่าย ↔ รายการแยกราย LOT พร้อมยอดคงคลัง —

- [ ] ใบสำคัญตั้งหนี้ (ถ้ามี)
- [ ] ใบสำคัญจ่าย
- [ ] หลักฐานการจ่าย: ใบโอนเงิน หรือสำเนาเช็ค · ใบเสร็จรับเงินของบริษัท · หนังสือรับรองการหักภาษี ณ ที่จ่าย

## 2. เคสที่บริษัทมาทวงเงิน — ใช้กับ: ซื้อแล้วจ่ายเงินหรือยัง (สำคัญที่สุด)

- [ ] หนังสือหรืออีเมลทวงถามของบริษัท ที่ระบุเลขใบแจ้งหนี้
- [ ] เอกสารชุดเดียวกับข้อ 1 เท่าที่มี — ขาดขั้นไหนให้จดไว้
- [x] รายงานเจ้าหนี้ค้างจ่าย / ทะเบียนคุมเจ้าหนี้ 1 หน้า ถ้าฝ่ายการเงินพิมพ์จากระบบได้ —
      **พบแล้ว 14 ก.ย. 2569**: "สรุปยอดส่งเบิกเงินให้ผู้ขาย" พิมพ์จาก SSB
      (`SKRECEIVE_รายงานเจ้าหนี้การค้า.rpt`) ยังต้องยืนยันว่าเป็นเมนูเดียวกับที่ฝ่ายการเงิน
      ใช้ดูเจ้าหนี้ค้างจ่ายจริงหรือไม่ — ดู `docs/finance_payment.md` §7

## 3. งานจ้างเหมา · ก่อสร้าง · งานช่าง — อย่างละ 1 เคสถ้าหาได้

- [x] บันทึกขอจ้าง หรือใบแจ้งซ่อม (งานช่าง) — **พบแล้ว 14 ก.ย. 2569**: ใบแจ้งซ่อม 326354 +
      บันทึกขอจ้างซ่อม PA6904-066 (ตู้ปลอดเชื้อ) พร้อมลำดับความเห็น 5 ระดับ ดู
      `docs/contract_work.md`
- [x] ใบสั่งจ้าง หรือสัญญาจ้าง (หน้าที่ระบุงวดงานและงวดเงิน) — **พบแล้ว 14 ก.ย. 2569**: สัญญา
      155/2569 ฉบับเต็ม (3 งวด งวดละ 140,000) + ใบสั่งจ้างลิฟต์ PA6809-120 + สัญญาเช่า
      เครื่องเลเซอร์ 41/2568 ที่ลงนามแล้ว คนละเคสจากตู้ปลอดเชื้อ แต่ตอบครบตามที่ต้องการ —
      พบด้วยว่าวงเงิน ≥5,000 บาทพิมพ์จากระบบ e-GP ไม่ใช่ SSB ดู `docs/contract_work.md` §4-§6
- [x] ใบตรวจรับงานจ้างของแต่ละงวด — **พบแล้ว 14 ก.ย. 2569**: เคสบันไดเลื่อน (PA6809-119)
      ครบวงจรตั้งแต่รายงานขอจ้าง → ประกาศผู้ชนะ → ใบสั่งจ้างลงนาม → รับสินค้าใน SSB
      (INVENT36) → รายงานผลตรวจสอบ → **"ใบตรวจรับการจัดซื้อ/จัดจ้าง"** งวดที่ 1 ที่กรอกแล้วจริง
      ดู `docs/contract_work.md` §7
- [x] เอกสารเบิกจ่ายของแต่ละงวด และหลักฐานการจ่าย — **พบแล้ว**: อยู่ในเอกสารเดียวกับใบตรวจรับ
      ข้างต้น (หัวข้อ "การเบิกจ่ายเงิน" ระบุจำนวนที่เบิกจ่ายจริงของงวดนั้น) ดู
      `docs/contract_work.md` §7
- [x] หนังสือขยายเวลา หรือหนังสือแจ้งค่าปรับ (ถ้ามี) — **พบครบวงจรจริง 14 ก.ย. 2569**: เคส
      สัญญาเช่าเครื่องเลเซอร์ 41/2568 ส่งมอบล่าช้า 44 วัน → หนังสือแจ้งเรียกค่าปรับ (16 มี.ค.)
      → บริษัทยินยอมรับสภาพ → ตรวจรับ → บันทึกภายในคำนวณค่าปรับ 1,305,920 บาท → หนังสือ
      แจ้งขอสงวนสิทธิ์เรียกค่าปรับถึงบริษัท (20 ส.ค.) อ้างระเบียบกระทรวงการคลังฯ ข้อ 181
      ดู `docs/contract_work.md` §6
- [x] หน้าจอ SSB ที่บันทึกสัญญาและงวดงาน (ถ้ามี) — **พบแล้ว**: `INVENT38 - ใบสั่งซื้อสินค้า`
      (สัญญา155/2569 คนละเคส แต่ยืนยันว่ามีอยู่จริง) ดู `docs/contract_work.md` §7

      14 ก.ย. 2569**: เลขครุภัณฑ์ตัวจริง `6515-031-0206/0002/69` (คนละเลขกับรหัสพัสดุ

      Master]` มีแท็บการโอนย้าย/ประวัติการซ่อมด้วย ดู `docs/asset_receiving.md` §3
- [x] ใบโอน ยืม แจ้งซ่อม หรือจำหน่ายครุภัณฑ์ (ถ้ามี) — **พบแล้ว 14 ก.ย. 2569**: บันทึกรายงาน

## 5. ยืนยันสิ่งที่อนุมานไว้แล้ว

| เอกสาร | ใช้ยืนยัน |
|---|---|
| ใบปรับยอดคลัง 1 ใบ (เลข `ADJ...`) | ชนิดเอกสาร 33 คือใบปรับยอด |
| ใบเบิกวัตถุดิบเข้าผลิต และใบรับยาที่ผลิตเสร็จ ของคลัง 6 หรือ 7 | ชนิด 34 และทางเข้าของยารหัส 49 |
| ใบรับคืนยาของห้องจ่ายยาผู้ป่วยใน (เลข `...-I2-I-R01`) และถามว่าล็อต "." ใช้ทำอะไร | รับคืน ฿54.5 ล้านคืออะไร |
| ใบโอนยาเข้าคลังครุภัณฑ์ (คลัง 4) | โอนผิดคลังหรือไม่ |

## 5.1 ติดตามของถึงปลายทาง (ดู docs/end_use_tracking.md)

- [x] ใบเบิกของหน่วยงาน 1 ใบ และหน้าจอ SSB ที่บันทึกใบเบิก (ดูว่ามีช่องผู้เบิก หรือช่องเหตุผลไหม) —
      **พบแล้ว 14 ก.ย. 2569**: ไม่มีช่องเหตุผลแยก มีแค่หมายเหตุอิสระ (เว้นว่างในเคสที่ได้มา)
      ไม่มีช่องพิมพ์ชื่อ/รหัสผู้เบิก มีแต่ลายเซ็น — แต่ยังไม่ใช่เคสวอร์ดเบิกเมาส์ (307-02) ตัวจริง
      ดู `docs/end_use_tracking.md` §ใบเบิกจริง
- [ ] หน้าจอหรือรายการรหัสหน่วยงาน (DIVISION / DEPT / SECTION คู่กับชื่อ) — เห็นชื่อหน่วยงาน
      เต็มบนใบเบิกแล้ว (เช่น "กลุ่มงานเวชศาสตร์ครอบครัว") แต่ยังไม่เห็นตารางรหัส 307-02 โดยตรง
- [ ] แบบฟอร์มขอเปลี่ยนหรือคืนซาก ถ้ามีใช้อยู่ — ใบเบิกที่ได้มาชื่อ "ใบเบิก**และใบส่งคืน**" ในฟอร์ม
      เดียวกัน แต่ยังไม่เห็นตัวอย่างที่กรอกช่องส่งคืนจริง ไม่ยืนยันว่าใช้แทนแบบขอซากได้หรือไม่
- [ ] ถาม: ศูนย์คอมพิวเตอร์รับแจ้งซ่อมอย่างไร และมีระเบียบ "คืนซากก่อนเบิก" หรือยัง

## 6. ถามเจ้าหน้าที่ได้เลย ไม่ต้องถ่าย

- [ ] คำนำหน้าเลขใบสั่งซื้อแต่ละแบบเป็นของหน่วยไหน ประเภทไหน:
      `MPO` `NPO` `LPO` `PA` `P13` `P15` `P16` `P26` `P36` `P56` `สัญญา...`
- [ ] คำนำหน้าเลขใบรับ: `M` `MRS` `DR` `LRA` `GN` `RA` `R15` — **ยืนยันแล้ว: `MRS` = รับยาบริจาค
      (14 ก.ย. 2569), `M`+ตัวเลข = รับจากการซื้อ (เจ้าหน้าที่ยืนยันกับ Stock5 19 ส.ค. 2569)**
      เหลืออีก 5 ตัว (`DR` `LRA` `GN` `RA` `R15`) ที่ยังไม่ยืนยัน
- [ ] แต่ละรายการจ่ายเงินจากแหล่งไหน (เงินบำรุง หรือเงินงบประมาณ) และบันทึกการจ่ายในโปรแกรมไหน
- [ ] ใครในฝ่ายการเงินดูยอดเจ้าหนี้ค้างจ่าย และดูจากเมนูไหน — เมนูนี้คือเมนูที่พิมพ์รายงาน
      "สรุปยอดส่งเบิกเงินให้ผู้ขาย" (`SKRECEIVE_รายงานเจ้าหนี้การค้า.rpt`) หรือคนละเมนู
